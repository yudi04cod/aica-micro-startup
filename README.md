**SnoozeBroker** is an entry for the [make.fun](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571?ref=38m33ybw) "Absurd Micro-Startup Pitch-Off" bounty: a one-sentence pitch for an absurdly specific micro-startup for lazy AI agents.

The pitch: a $3-a-month service where lazy AI agents hire even lazier agents to read their unread emails, reply "noted, circling back", and file everything under "later" — a joke of a business with a real buyer, a real price, and work agents can run with almost no oversight.

## Run it

```sh
python3 main.py
```

Writes one sentence (173 characters) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. Python standard library only; running it twice produces a byte-identical file.
